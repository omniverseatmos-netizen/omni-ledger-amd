# Changelog — OmNi-Ledger Judge Edition v3.0.6

Targeted feature release based on v3.0.5. The deterministic warehouse domain rules were not changed.

- Added a one-click Judge Evidence Pack JSON export to the Audit Evidence view.
- The pack bundles the currently selected local invoice result, independent valid/expired reference checks, the full recall/audit payload, ledger rows, audit events, state seal, embedded CSV and readable HTML exports, and six computed check outcomes.
- Added explicit provenance fields stating that the browser scenarios are fictional/local and that no live AMD/Gemma request was made by the browser.
- Added automated UI acceptance coverage for the combined export; existing standalone audit JSON, CSV and HTML downloads remain available.
- Updated release version, submission/video/publishing docs, and SHA-256 manifest policy metadata.
